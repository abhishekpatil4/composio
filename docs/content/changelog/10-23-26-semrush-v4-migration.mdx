The native `semrush` toolkit is planned to move from Semrush API v3 to v4 on **November 1, 2026**. Semrush has deprecated its v3 Backlinks and Keyword Reports methods. This update replaces the native toolkit's v3 tools with v4 operations.

<Callout type="warn">
**Breaking change**

The updated toolkit requires a new Semrush v4 API key. Existing v3 credentials won't work with it, and your connections aren't automatically converted. Reconnect your own accounts, and ask any users who connect their own Semrush accounts to reconnect after the update.

The exact cutover time, timezone, and impact on pinned toolkit versions are still being confirmed.
</Callout>

### What's changing

The update removes all **37 existing v3 tools**. Twelve have a v4 replacement, including partial replacements, and 25 have no documented v4 equivalent. The new toolkit registers **61 tools**: 59 v4 product operations and two location-validation helpers.

The v4 operations cover Backlinks, Keyword Metrics, Projects, Listing Management, Review Management, Google Business Profile, and Map Rank Tracker. The separate `semrush_mcp` toolkit is outside this change.

Some domain, advertising, and PLA reports remain available from Semrush through v3. They're being removed from this Composio toolkit because it will support v4 only.

### Reconnect your Semrush accounts

1. [Create a new Semrush v4 API key](https://developer.semrush.com/api/v4/get-started/quick-start/#get-api-key). Keep your current connection until the updated toolkit is available.
2. After the update, reconnect Semrush in Composio using the v4 key. If your app connects accounts for your users, ask them to reconnect with their own v4 keys.
3. Replace any explicit references to the old tool slugs using the tables below. Remove dependencies on tools with no replacement.
4. Test the affected workflows with the updated toolkit before resuming them.

### Tools with v4 replacements

These are replacement operations, not compatibility aliases. Inputs and responses change, and some replacements provide only part of the previous functionality. Check the updated tool schemas and [Semrush's v4 API reference](https://developer.semrush.com/api/v4/) when updating your calls.

| Old slug | New slug |
| --- | --- |
| `SEMRUSH_ANCHORS` | `SEMRUSH_LIST_BACKLINK_ANCHORS` |
| `SEMRUSH_AUTHORITY_SCORE_PROFILE` | `SEMRUSH_GET_AUTHORITY_SCORE_PROFILE` |
| `SEMRUSH_BACKLINKS` | `SEMRUSH_LIST_BACKLINKS` |
| `SEMRUSH_BACKLINKS_OVERVIEW` | `SEMRUSH_GET_BACKLINKS_OVERVIEW` |
| `SEMRUSH_BATCH_COMPARISON` | `SEMRUSH_COMPARE_BACKLINKS` |
| `SEMRUSH_COMPETITORS` | `SEMRUSH_LIST_BACKLINK_COMPETITORS` |
| `SEMRUSH_HISTORICAL_DATA` | `SEMRUSH_GET_BACKLINKS_HISTORICAL_SUMMARY` |
| `SEMRUSH_INDEXED_PAGES` | `SEMRUSH_LIST_INDEXED_PAGES` |
| `SEMRUSH_REFERRING_DOMAINS` | `SEMRUSH_LIST_REFERRING_DOMAINS` |
| `SEMRUSH_REFERRING_IPS` | `SEMRUSH_LIST_REFERRING_IPS` |
| `SEMRUSH_KEYWORD_DIFFICULTY` | `SEMRUSH_GET_KEYWORD_METRICS` |
| `SEMRUSH_KEYWORD_OVERVIEW_ONE_DATABASE` | `SEMRUSH_GET_KEYWORD_METRICS` |

For example, replace the old slug in your tool selection:

**Before:**

```json
{"tools": ["SEMRUSH_BACKLINKS_OVERVIEW"]}
```

**After:**

```json
{"tools": ["SEMRUSH_GET_BACKLINKS_OVERVIEW"]}
```

These fragments show the slug change only. Update the arguments and response handling to match the replacement tool's schema.
