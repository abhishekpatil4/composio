The native `semrush` toolkit is planned to move from Semrush API v3 to v4 on **November 1, 2026**. Semrush has deprecated its v3 Backlinks and Keyword Reports methods. This update replaces the native toolkit's v3 tools with v4 operations.

<Callout type="warn">
**Breaking change**

The updated toolkit requires a Semrush v4 API key. Existing v3 credentials and connections won't work with it. You or your users will need a new v4 key and must reconnect after the update.
</Callout>

You can also use the separate `semrush_mcp` toolkit in the interim. Its setup and available tools differ from the native toolkit.

### Reconnect your Semrush accounts

[Get a new Semrush v4 API key](https://developer.semrush.com/api/v4/get-started/quick-start/#get-api-key), then reconnect Semrush to Composio using that key after the update. Keep your current connection until then.
