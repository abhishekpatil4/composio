The [Semrush toolkit](/toolkits/semrush) is planned to move from Semrush API v3 to v4 on **November 1, 2026**. (Alternatively, you can also use the [Semrush MCP toolkit](/toolkits/semrush_mcp).) Semrush has deprecated its v3 Backlinks and Keyword Reports methods.

<Callout type="warn">
**Breaking change**

The updated toolkit requires a Semrush v4 API key. Existing v3 credentials and connections won't work with it. You or your users will need a new v4 key and must reconnect after the update.
</Callout>

### Reconnect your Semrush accounts

[Get a new Semrush v4 API key](https://developer.semrush.com/api/v4/get-started/quick-start/#get-api-key), then reconnect Semrush to Composio using that key after the update. Keep your current connection until then.

### New tools

Alongside the updated Backlinks and Keyword Metrics tools, we're adding the following tool groups:

| Tool group | New tools | What you can do |
| --- | --- | --- |
| Projects | 5 | List, create, view, update, and delete Semrush projects. |
| Listing Management | 14 | Manage business locations, directory listings, images, and listing details. |
| Review Management | 7 | Read reviews, manage replies, and configure automatic replies. |
| Google Business Profile | 10 | View metrics, manage posts and suggestions, and look up categories and attributes. |
| Map Rank Tracker | 11 | Manage campaigns and view local rankings, heatmaps, and competitors. |
